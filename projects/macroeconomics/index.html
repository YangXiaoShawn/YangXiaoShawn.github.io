Project overview

The project studies macro release revisions and real-time sample windows for forecast performance, covering standardized data ingestion, timeline alignment, back-testing, and release documentation.

The current site keeps publish-ready entry points and lightweight examples for review and external sharing.

Release constraints

  • Some external data sources require additional permission checks before going live.
