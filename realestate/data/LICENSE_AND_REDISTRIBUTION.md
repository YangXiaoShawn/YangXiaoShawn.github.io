# License and Redistribution Policy

This repository's **code** is MIT-licensed. This repository's **data handling** is
governed by the rules below, which are stricter than the code licence and which
override convenience in every case.

---

## 1. What may be committed

| Category | Committed? | Location |
|---|---|---|
| Source code, adapters, schemas, field maps | Yes | `src/`, `tests/` |
| Download instructions | Yes | `data/DATA_ACCESS.md` |
| Our own encoding of the official Freddie Mac field layout (names, positions, types, enumerations) | Yes — this is metadata about a public specification, not data | `data/reference/freddie_llds_layout.yaml` |
| Small committed reference tables (state FIPS, census divisions, coupon bin edges) | Yes | `data/reference/` |
| **Labeled synthetic** loan fixtures | Yes — tiny, clearly marked `SYNTHETIC` | `data/fixtures/` |
| Manifests (metadata only: URL, checksum, row count, coverage) | Yes | alongside their data, `*.manifest.json` |
| Aggregated, non-restricted outputs (e.g. state-month counts from public HMDA aggregations) | Yes, if small | `data/reference/` on explicit decision only |
| Downloaded public series (PMMS, FHFA HPI, BPS, HMDA responses) | **No** — cached, not committed | `data/cache/` (gitignored) |
| Registered Freddie Mac loan-level files | **Never** | `data/raw/` (gitignored) |
| Anything derived from registered loan-level data at loan granularity | **Never** | `data/interim/`, `data/processed/` (gitignored) |
| Result artifacts | No — regenerated by `make reproduce-sample` | `outputs/` (gitignored) |

`.gitignore` enforces this mechanically. `tests/test_governance.py` asserts that
no tracked file matches a restricted-data pattern and that no tracked file exceeds
a size budget.

## 2. Per-source terms as we understand them

We are not lawyers and this is not legal advice. Where terms are ambiguous we take
the restrictive reading.

### Freddie Mac Single-Family Loan-Level Dataset — **RESTRICTED**
- Requires registration and acceptance of Freddie Mac's terms of use.
- Redistribution of the loan-level records is **prohibited**.
- **Our handling:** never committed, never uploaded, never included in reports at
  loan granularity. Reports contain aggregates and model coefficients only. The
  adapter reads from a local path the user populated themselves.
- We do not attempt to circumvent the registration wall. The publicly available
  `user_guide.pdf` and `file_layout.xlsx` are used for the schema; those are
  served without authentication.

### Freddie Mac Primary Mortgage Market Survey — **ATTRIBUTION, NON-COMMERCIAL REDISTRIBUTION RESTRICTED**
- Freddie Mac permits use of PMMS with attribution. Commercial redistribution of
  the series is restricted.
- **Our handling:** cached locally, not committed. Charts and tables cite
  "Freddie Mac Primary Mortgage Market Survey" with the retrieval date.
- Aggregate statistics derived from PMMS (e.g. a monthly average) appear in
  reports with attribution.

### FHFA House Price Index — **PUBLIC DOMAIN (U.S. Government work)**
- Freely usable. Cite FHFA and the release.
- **Our handling:** cached, not committed (size, not licence). Derived index
  growth rates appear in reports.

### HMDA (CFPB / FFIEC) — **PUBLIC**
- The public LAR and the Data Browser are published for public use. The public
  release already carries **privacy modifications** applied by the CFPB
  (binning, rounding, omission of some fields) to protect applicant privacy.
- **Our handling:** we use the aggregations endpoint, which returns counts and
  dollar sums only. We do not attempt to re-identify, link, or reverse the
  privacy modifications. We do not download the loan-level LAR in this project.

### Census Building Permits Survey — **PUBLIC DOMAIN (U.S. Government work)**
- Freely usable. Cite the Census Bureau and the file vintage (`c` preliminary vs
  `r` revised).

### FRED (Federal Reserve Bank of St. Louis) — **SERIES-DEPENDENT**
- FRED redistributes third-party series under the original provider's terms.
  `MORTGAGE30US` originates with Freddie Mac, so PMMS terms apply.
- **Our handling:** used only as a cross-check on our direct PMMS fetch.

### BLS LAUS — **PUBLIC DOMAIN**, with an access-etiquette requirement
- BLS asks that automated downloads identify themselves with a contact
  `User-Agent`. Our adapter does so and backs off on 403/429. It is optional.

## 4. Synthetic-data labeling rules

1. Synthetic loan fixtures are generated by `lockin.fixtures.make_synthetic_cohort`
   from an explicit seed recorded in the manifest.
2. Their manifest sets `redistribution_status: "synthetic — freely redistributable"`
   and `data_class: "SYNTHETIC"`.
3. Every result artifact computed from them sets `data_class: "SYNTHETIC"`.
4. Every generated report renders a banner at the top when any input is synthetic:

   > ⚠️ **SYNTHETIC DATA.** The loan-level numbers in this report were computed
   > from synthetic fixtures generated for engineering tests. They are **not**
   > empirical findings about U.S. mortgages. Public aggregate series (PMMS, FHFA
   > HPI, HMDA, Census BPS) in this report are real.

5. The report renderer raises if `data_class == "SYNTHETIC"` and the banner is
   absent. There is no flag to disable this.

## 5. If you find a violation

Delete the offending file from the working tree, add the pattern to `.gitignore`,
and — if it was committed — treat the history as contaminated and rewrite it
before pushing anywhere. Record the incident in `docs/DECISION_LOG.md`.
