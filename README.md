# Open Economic & Quant Research Observatory (GithubIO)

This repository contains a publication-ready website for two research projects:

- CasualLab
- Macroeconomics

It also includes release metadata and verification artifacts under:

- `manifests/`
- `docs/`

Upload-ready project copies are stored at:

- `casuallab/`
- `macroeconomics/`

An internal mirror used for checklist verification is also kept at:

- `upload_ready/`

From this folder, run:

```bash
cd "/Users/shawn/Documents/intern projects/GithubIO"
python3 scripts/validate_projects.py
python3 scripts/verify_deployment.py
```
